# GIFs für die VIP-Willkommensnachricht

Leg hier ein paar animierte GIFs ab (Endung `.gif`) — z.B. Konfetti, Feuer,
Krone, "Welcome"-Animationen. Kostenlos runterladen von
[giphy.com](https://giphy.com) oder [tenor.com](https://tenor.com) (auf der
GIF-Seite meist ein Download-Button, oder Rechtsklick → "Grafik speichern
unter...").

Bei jeder VIP-Willkommensnachricht wählt der Bot automatisch zufällig eins
davon aus. Ist der Ordner leer, gibt's einfach kein GIF (Rest der Nachricht
funktioniert trotzdem normal).

Diese Datei kannst du löschen, sobald echte GIFs hier liegen.
