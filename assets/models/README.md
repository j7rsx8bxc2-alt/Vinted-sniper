# Model-Fotos für !tryon

Leg hier deine KI-generierten Model-Fotos ab (.jpg, .jpeg, .png oder .webp).
`!tryon` wählt bei jedem Aufruf automatisch zufällig eins davon aus.

Wichtig: nur synthetische/KI-generierte Fotos verwenden (z.B. von
https://www.bing.com/images/create oder https://thispersondoesnotexist.com),
keine echten Personenfotos von Google, Pinterest, Vinted o.ä. — das wäre ein
Urheber- und Persönlichkeitsrechte-Risiko für dein Business.

Diese Datei kannst du löschen, sobald echte Model-Fotos hier liegen.
